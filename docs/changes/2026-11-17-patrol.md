## Scope and decisions

- Compared **60 text-generation trends**, **30 image-text trends**, a bounded
  60-upload recent-text sample and five recent repositories each from 12 major
  publishers with the index and pending list. These are bounded discovery samples,
  not an exhaustive scan of every Hub upload. Conversion uploads are not assumed
  to be original model releases. Existing Arete, TwIL, LFM3, Nanbeige, Qwen and
  DeepSeek entries were checked for duplicates.
- Added **three checkpoint entries**: Pocket Instruct and Pocket QAT are separate
  weights, plus BotPsy. Index becomes **145 total / 125 active**, with **143
  recorded licences** and **39 image-input entries**. No GPU inventory changed.
- Pocket has an official GGUF repository now reachable in the search. Its
  November 10 last-modified timestamp is not evidence of a November 17 release;
  this is a gap-audit inclusion, correcting the earlier unresolved search result.
- Read original model configs/cards and licence text, official file listings and
  actual GGUF metadata/tensor dimensions. The GGUF headers reveal why rounded
  names and aggregate original-repository totals cannot determine file memory.
- Pocket QAT preserves trained UINT4 codes, uses tied embeddings and contains
  **302,830,976** tensor parameters. BF16-derived Q8_0 stores a separate output
  table, **361,551,232** parameters. The difference is exactly **58,720,256**
  (896 × 65,536), verified from `output.weight`; do not mix these checkpoints.
- Pocket config and both GGUF headers allow **40,960** context, while the model
  card documents **32K**. Both index entries conservatively expose **32,768**.
  28 full-attention layers, 14 query heads, 2 KV heads × 64; no vision encoder.
- BotPsy GGUFs contain **752,393,024** language parameters, versus the original
  safetensors aggregate **852,985,920** including vision. The official GGUF pack
  contains no projector; the original card describes tool calling, not a verified
  image workflow. It is indexed for text only. 24 layers, 8 query heads, 2 KV heads
  × 256, 262,144 context, six full-attention layers; the existing qwen35 hybrid
  model applies. Fixed recurrent state remains outside the explicit cache term,
  as with existing Qwen3.5 entries; this is an estimate, not a measured GPU run.
- Added the standard GGUF **Q4_1** selection. Upstream `block_q4_1` stores 20 bytes
  per 32 weights (5-bit block rate); actual model rows always use file-derived
  bpw. Q4_1 is a quant level, not a new format. Model reference selection accepts
  it before falling back to the highest-bit file.
- Found duplicate homepage pick IDs 36/37: Arete/TwIL reused Liquid's IDs.
  Assigned unique IDs 40/41, new entries 42–44; picks now sort by model `addedAt`
  before their ID tie-break and before slicing. A duplicate-ID data invariant
  prevents recurrence. No model or historical entry is deleted.

## Model sizing inputs and limits

- Arete: publisher metadata 27,356,728,560 parameters; config 64 layers, 24 attention
  heads, 4 KV heads × 256, 262,144 context, 16 growing-cache layers. GGUF language
  bytes: Q3_K_M 13,165,067,264; Q4_K_M 17,203,416,064; Q5_K_M 20,684,893,184;
  Q8_0 28,665,068,544. Optional f16 projector 927,607,104 bytes. Per-row bpw is
  `language bytes * 8 / publisher parameter count`, so file weight memory is exact
  as an input even though runtime memory is estimated. Fixed recurrent state is
  not separately sized, consistent with the existing Qwen hybrid estimate.
- TwIL balanced: 8,791,592,960 parameters, independently reconciled with the config:
  two 4096×100352 token tables plus 40 dense-attention/MLP blocks and norms.
  40 layers, 32 attention heads, 8 KV heads × 128, 131,072 context. Only recorded
  file: `TwIL-8B-Q4_K_M-balanced.gguf`, 5,347,917,568 bytes. The other three official
  GGUFs are verbose weights and are deliberately excluded from this entry.
- Shared calculator at 4K / single sequence / f16 KV / text-only: Arete Q3_K_M
  14.03 GiB, Q4_K_M 18.25 GiB, Q5_K_M 21.89 GiB, Q8_0 30.23 GiB; TwIL Q4_K_M
  6.28 GiB. These are estimates, not new measured runs. No speed or PPL is added.

# 2026-11-25 quantized.uk patrol

Compared recent and trending text generation and image-text-to-text entries on
Hugging Face, 17 publisher feeds, the existing catalogue and pending list.

## Catalogue additions

The catalogue now has 164 models, including 144 active, 162 with licence data
and 55 with image input. The four additions have publisher Apache 2.0 terms.
The table shows exact download bytes. Language parameter counts are sums of
the Q4_K_M or Q2_0 GGUF file's tensor element counts. The projector is counted
separately for image input.

- **Ternary Bonsai 2.5 27B.** The official Q2_0 is the base Hadamard-rotated
  file. Its `qwen35` header has 64 layers, 24 query heads, four 256-wide KV heads,
  16 full-attention layers and 262,144 positions. The BF16 projector header
  has 27 vision blocks. The publisher points to merged llama.cpp PR #29600 and
  b11556 or later for stock Q2_0. Commands for this packing use llama.cpp.
  Ollama import of the rotation metadata remains unverified. PQ2_0 and PTQ1_0
  use the publisher's separate kernels. Draft-head and fork-specific files are
  outside this sizing row. [Publisher card and demo](https://huggingface.co/prism-ml/Ternary-Bonsai-2.5-27B-GGUF) · [GGUF listing](https://huggingface.co/prism-ml/Ternary-Bonsai-2.5-27B-GGUF/tree/main) · [Upstream support](https://github.com/ggml-org/llama.cpp/pull/29600)
- **CCORE Web Coder 4B.** The November 23 final Q8_0 replaces the preview
  under the same name. Both current files contain the same shapes and count.
  The official Q4_K_M header advertises 33 blocks and one NextN block, but
  the tensor directory contains only the 32-block trunk. The pinned
  llama.cpp loader marks a missing NextN head optional and skips it in
  ordinary text inference. The estimate models 32 layers, eight full,
  16 query and four 256-wide KV heads, with 262,144 positions. The original
  24-block F16 vision tower is an optional projector for experiments.
  [Publisher card](https://huggingface.co/ccore/CCORE-Web-Coder-4B) · [Config](https://huggingface.co/ccore/CCORE-Web-Coder-4B/blob/main/config.json) · [Files](https://huggingface.co/ccore/CCORE-Web-Coder-4B/tree/main) · [Pinned trunk/MTP loader](https://github.com/ggml-org/llama.cpp/blob/b12409/src/llama-model.cpp)
- **MiniCPM-V 4.6 and Thinking.** Both official configs and Q4_K_M headers
  describe a `qwen35` trunk with 24 layers, six full, eight query heads and
  two 256-wide KV heads, with 262,144 positions. Separate official weights
  and F16 projectors are used for each. The base and Thinking cards document
  llama.cpp running the respective GGUF repositories. The public cards
  describe image/video support, while the sizing figure adds the exact vision
  weights and uses the selected context for KV.
  [Base card/config](https://huggingface.co/openbmb/MiniCPM-V-4.6) · [Base GGUF](https://huggingface.co/openbmb/MiniCPM-V-4.6-gguf/tree/main) · [Thinking card/config](https://huggingface.co/openbmb/MiniCPM-V-4.6-Thinking) · [Thinking GGUF](https://huggingface.co/openbmb/MiniCPM-V-4.6-Thinking-gguf/tree/main)

Runtime support and estimates come from file metadata and source inspection.
No GPU run, throughput or quality figure was added.

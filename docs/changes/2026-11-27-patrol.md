# 2026-11-27 quantized.uk patrol

Synced main at `0c81b6a`. The intervening release had already indexed Inkling 2
Mini, Domyn Edge SFT and Mellum2.1 Instruct and moved the Windows llama.cpp pin
to b12774. This patrol compared the newest and trending text-generation and
image-text-to-text lists on Hugging Face, 17 publisher feeds, the existing
catalogue and pending entries. [Text models](https://huggingface.co/models?pipeline_tag=text-generation&sort=trending) · [Vision-language models](https://huggingface.co/models?pipeline_tag=image-text-to-text&sort=trending) · [November 26 release](2026-11-26-models-v1-1-and-layout-redesign.md)

## Catalogue additions

**Micius-Flash 27B** is Zhiman's vision-language checkpoint for semiconductor
engineering and hardware design. Its November 23 checkpoint configuration
specifies 64 Qwen3.5 layers, including 16 full-attention layers, with 24 query
heads, four 256-wide KV heads and a 262,144-token context. The other 48 layers
use fixed Gated DeltaNet state outside the growing KV estimate. The Q4_K_M
GGUF header at revision `cfdbb77fdb9356a0cfed773609b6e243411995bc` matches
that layout and contains 26,895,998,464 language tensor elements. The
separate F16 projector header reports 27 blocks and weighs 927,607,264 bytes.
The original licence permits non-commercial research and allows derivative
publication under the same restrictions. ## Verification and deployment

Before editing, production `npm run check:live` passed 25 checks with the
environment HTTP proxy enabled for Node. This included both languages at
390 × 844, the reverse calculator, Hub disclosure/search, canonical model/GPU
pair pages and share-previews. The Qwen3 8B result grew from 5.81 to 6.43 GiB
when context increased from 4K to 8K in each language.

- On the previous production release, a 390 px Chromium probe reproduced a
  quick-launch copy target under 44 px and silent failure when clipboard
  writing was denied in both languages. The same probe on the new export
  verified manual selection, feedback, normal copying and the 44 px
  controls on all four new detail pages. The tests also covered exact
  llama.cpp and Ollama filenames, calculator results, the pending page,
  report links, the AMD ROCm guide, both homepages and public changelogs.
- Final data tests passed with 171 models and 400 eligible model/GPU pairs
  per language. The forward, reverse, imported, embed and share sizing
  consistency suites passed.
- The first build hit a Google Fonts CSS response that the Next 14 font
  loader could not parse in this proxy environment. Replaying fresh
  upstream CSS and WOFF2 files through the Next font cache reached type
  checking, which caught a misplaced component prop. The prop was moved
  to the actual quick-launch component and the full build rerun with
  those same font assets. Both remedies were local to validation except
  for the prop correction. The final export passed the language, metadata,
  structured-data and file-count gates (1,580 HTML pages and 4,002 files).
- The local sitemap lists 1,574 unique URLs. Both RSS feeds carry all four
  additions. Sampled reference-quant bytes and projector bytes match the
  171-model public JSON.
- The stock local 390 px phone probe intermittently reached the Chinese
  Hub search box while it was mounting. After adding an explicit visibility
  wait to the local probe, both languages passed the complete phone checklist.
  The repository smoke script stays unchanged.

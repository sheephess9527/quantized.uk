## Site fixes

- A `zh-TW` phone probe reproduced a browser tab title that stayed in
  Traditional Chinese after switching the page back to Simplified Chinese.
  The switch now retains the original title across toggles and refreshes it
  when the page supplies a different title.
- llama.cpp b12774 lists `--draft-max` as removed and calls the MTP mode
  `draft-mtp`. The CLI generator and Speed Feel now use
  `--spec-draft-n-max` with the current MTP, DFlash2 or separate-draft mode.
  Speed Feel identifies its speed and memory values as simulation assumptions
  and only offers a llama.cpp template for a recorded GGUF filename.
  The templates still require a compatible draft or embedded MTP head.
  [Pinned CLI reference](https://github.com/ggml-org/llama.cpp/blob/b12774/tools/cli/README.md)
- The CLI generator puts concurrency, GPU splitting and applicable draft
  flags into the actual server command, including PowerShell and Compose.
  Container draft paths point into the existing model mount. vLLM's Compose
  settings now reach the service instead of appending to its HTTP test command.
  [vLLM serve reference](https://docs.vllm.ai/en/v0.34.0/cli/serve/)
